NAME

gcloud firestore - manage your Cloud Firestore resources

SYNOPSIS

`gcloud firestore` [`GROUP`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore#GROUP) \| [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

export -- Export data to Google Cloud Storage

import -- Import data from Google Cloud Storage

bulk-delete -- Bulk delete documents from Cloud Firestore

indexes -- Manage your Cloud Firestore indexes

operations -- Manage Long Running Operations for Cloud Firestore

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

GROUPS

`GROUP` is one of the following:

[`backups`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/backups)  
The set of commands to manage backups for Cloud Firestore.

[`databases`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/databases)  
Manage Creation of Cloud Firestore in Native mode Database.

[`fields`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/fields)  
Manage field metadata for Cloud Firestore.

[`indexes`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/indexes)  
Manage indexes for Cloud Firestore.

[`locations`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/locations)  
The set of commands to manage Locations for Cloud Firestore.

[`operations`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/operations)  
Manage Long Running Operations for Cloud Firestore.

[`user-creds`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/user-creds)  
Manage the user creds for a Cloud Firestore Database.

COMMANDS

`COMMAND` is one of the following:

[`bulk-delete`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/bulk-delete)  
bulk delete Cloud Firestore documents.

[`export`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/export)  
export Cloud Firestore documents to Google Cloud Storage.

[`import`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/import)  
import Cloud Firestore documents from Google Cloud Storage.

NOTES

These variants are also available:

```
gcloud alpha firestore
```

