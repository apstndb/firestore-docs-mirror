NAME

gcloud datastore operations - manage Long Running Operations for Cloud Datastore

SYNOPSIS

`gcloud datastore operations` [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/datastore/operations#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/datastore/operations#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

Manage Long Running Operations for Cloud Datastore.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

COMMANDS

`COMMAND` is one of the following:

[`cancel`](https://docs.cloud.google.com/sdk/gcloud/reference/datastore/operations/cancel)  
Cancel a currently-running Cloud Datastore admin operation.

[`delete`](https://docs.cloud.google.com/sdk/gcloud/reference/datastore/operations/delete)  
Delete a completed Cloud Datastore admin operation.

[`describe`](https://docs.cloud.google.com/sdk/gcloud/reference/datastore/operations/describe)  
Retrieves information about a Cloud Datastore admin operation.

[`list`](https://docs.cloud.google.com/sdk/gcloud/reference/datastore/operations/list)  
List pending Cloud Datastore admin operations and their status.

NOTES

These variants are also available:

```
gcloud alpha datastore operations
```

```
gcloud beta datastore operations
```
