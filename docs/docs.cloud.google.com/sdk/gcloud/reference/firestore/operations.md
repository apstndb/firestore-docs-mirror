NAME

gcloud firestore operations - manage Long Running Operations for Cloud Firestore

SYNOPSIS

`gcloud firestore operations` [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/operations#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/operations#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

Manage Long Running Operations for Cloud Firestore.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

COMMANDS

`COMMAND` is one of the following:

[`cancel`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/operations/cancel)  
Cancel a currently-running Cloud Firestore admin operation.

[`delete`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/operations/delete)  
Delete a completed Cloud Firestore admin operation.

[`describe`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/operations/describe)  
Retrieves information about a Cloud Firestore admin operation.

[`list`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/operations/list)  
List pending Cloud Firestore admin operations and their status.

NOTES

These variants are also available:

```
gcloud alpha firestore operations
```

```
gcloud beta firestore operations
```
