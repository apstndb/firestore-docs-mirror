NAME

gcloud firestore user-creds - manage the user creds for a Cloud Firestore Database

SYNOPSIS

`gcloud firestore user-creds` [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/user-creds#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/user-creds#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

Manage the user creds for a Cloud Firestore Database.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

COMMANDS

`COMMAND` is one of the following:

[`create`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/user-creds/create)  
Creates a Cloud Firestore user creds.

[`delete`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/user-creds/delete)  
Deletes a Cloud Firestore user creds.

[`describe`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/user-creds/describe)  
Describes a Cloud Firestore user creds.

[`disable`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/user-creds/disable)  
Disables a Cloud Firestore user creds.

[`enable`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/user-creds/enable)  
Enables a Cloud Firestore user creds.

[`list`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/user-creds/list)  
Lists user creds under a Cloud Firestore database.

[`reset-password`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/user-creds/reset-password)  
Resets a Cloud Firestore user creds.

NOTES

These variants are also available:

```
gcloud alpha firestore user-creds
```

```
gcloud beta firestore user-creds
```
