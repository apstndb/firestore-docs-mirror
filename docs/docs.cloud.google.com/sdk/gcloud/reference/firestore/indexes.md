NAME

gcloud firestore indexes - manage indexes for Cloud Firestore

SYNOPSIS

`gcloud firestore indexes` [`GROUP`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/indexes#GROUP) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/indexes#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

Manage indexes for Cloud Firestore.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

GROUPS

`GROUP` is one of the following:

[`composite`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/indexes/composite)  
Manage composite indexes for Cloud Firestore.

[`fields`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/indexes/fields)  
Manage single-field indexes for Cloud Firestore.

NOTES

These variants are also available:

```
gcloud alpha firestore indexes
```

```
gcloud beta firestore indexes
```
