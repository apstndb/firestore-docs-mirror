NAME

gcloud firestore change-streams - manage Cloud Firestore ChangeStreams

SYNOPSIS

`gcloud firestore change-streams` [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/change-streams#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/change-streams#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

Change streams are only available on Enterprise edition databases.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

COMMANDS

`COMMAND` is one of the following:

[`create`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/change-streams/create)  
Create a Cloud Firestore change stream.

[`delete`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/change-streams/delete)  
Delete a Cloud Firestore change stream.

[`describe`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/change-streams/describe)  
Describe a Cloud Firestore change stream.

[`list`](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/change-streams/list)  
List change streams under a Firestore database.

NOTES

These variants are also available:

```
gcloud alpha firestore change-streams
```

```
gcloud beta firestore change-streams
```
