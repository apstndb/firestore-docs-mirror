# Search (Transformation Stage)

## Description

Allows performing various types of searches within a collection or collection group. Must be the first stage in the pipeline.

## Examples and Behavior

See examples of [text search queries](https://docs.cloud.google.com/firestore/native/docs/text-search) and [geospatial search queries](https://docs.cloud.google.com/firestore/native/docs/geospatial-query) .
