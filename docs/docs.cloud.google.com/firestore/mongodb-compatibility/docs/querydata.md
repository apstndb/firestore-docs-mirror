# Query databases in natural language with QueryData

> **Preview**
>
> This feature is subject to the "Pre-GA Offerings Terms" in the General Service Terms section of the [Service Specific Terms](https://docs.cloud.google.com/terms/service-terms#1) . Pre-GA features are available "as is" and might have limited support. For more information, see the [launch stage descriptions](https://cloud.google.com/products/#product-launch-stages) .

QueryData lets you interact with the data in your Firestore with MongoDB compatibility database using conversational language and build data agents. You provide database-specific information in the form of context sets to improve generator accuracy.

## Context sets

A context set is a collection of database-specific information that enables QueryData to generate queries with high accuracy.

To learn more, see:

- [Context sets overview](https://docs.cloud.google.com/gemini/data-agents/querydata/firestore-mongodb-compatibility/context-sets-overview)
- [Build context sets using the context engineering agent](https://docs.cloud.google.com/gemini/data-agents/querydata/firestore-mongodb-compatibility/build-context-sets)
- [Manage context sets in](https://docs.cloud.google.com/gemini/data-agents/querydata/firestore-mongodb-compatibility/manage-data-agents)

## QueryData

QueryData writes queries for your database using context sets, translating natural language questions into accurate MongoDB-compatible Query Language (MQL) queries.

To learn more, see :

- [QueryData overview](https://docs.cloud.google.com/gemini/data-agents/querydata/firestore-mongodb-compatibility/data-agent-overview)
- [Test QueryData in Firestore](https://docs.cloud.google.com/gemini/data-agents/querydata/firestore-mongodb-compatibility/inspect-data-agent)
- [Integrate QueryData with an application](https://docs.cloud.google.com/gemini/data-agents/querydata/firestore-mongodb-compatibility/integrate-applications-data-agent)
